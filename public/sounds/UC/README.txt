Thư mục âm thanh vòng thi ĐẤU TRÍ (University Challenge)
Đường dẫn: /public/sounds/UC/

Danh sách các file âm thanh:
1. UC_Start.mp3        - Nhạc hiệu khi chọn/vào vòng Đấu Trí
2. UC_Begin.mp3        - Nhạc hiệu chuẩn bị vòng Đấu Trí (nút "Chuẩn bị")
3. UC_Reminder.mp3     - Cảnh báo khi còn 3:03 trên đồng hồ hoặc còn 3 câu hỏi chính
4. UC_Last3Minutes.mp3 - Cảnh báo 3 phút cuối cùng (3:00)
5. UC_End.mp3          - Nhạc hiệu kết thúc phần thi / hết thời gian
6. UC_CorrectMain.mp3  - Phát khi thí sinh trả lời đúng câu hỏi chính
7. UC_CorrectBonus.mp3 - Phát khi thí sinh trả lời đúng câu hỏi thưởng
8. UC_Wrong.mp3        - Phát khi thí sinh trả lời sai câu hỏi

Lưu ý:
Bạn có thể thả trực tiếp các file MP3 với đúng tên ở trên vào thư mục public/sounds/UC/ này.
Nếu chưa có file MP3 thực tế, hệ thống sẽ tự động phát âm thanh mô phỏng qua Web Audio API!
