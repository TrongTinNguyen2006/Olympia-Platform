Lưu ý:
Bạn có thể copy/thả trực tiếp các file MP3 với đúng tên ở trên vào thư mục public/sounds/ này để thay thế âm thanh mặc định.
Nếu chưa có file MP3, hệ thống sẽ tự động sử dụng bộ tổng hợp âm thanh Web Audio API tích hợp sẵn!
